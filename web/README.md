Provision Demo
==============

This tool is very beta and will be entirely replaced in the near
future.

It is currently available [here](https://firefly.box/demo-provision/)
but that link will change as we get a full
[firefly.box](https://firefly.box) development site built.


Running
-------

This uses the `dist` build directly from the project, so it must
be run with access to that, one folder up from the web folder.

This will change in the future.

```
# Start the webserver
/home/ricmoo/firefly-repl> python3 -m http.server 8000

# Navigate to: http://localhost:8000/web/
```
